 ⌚ Apple Watch UI

Interface inspirada no Apple Watch, desenvolvida com foco em prática de design responsivo, posicionamento de elementos e construção de interfaces modernas.

🧠 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de reproduzir e adaptar a interface de um Apple Watch para o ambiente web, explorando conceitos de layout, responsividade e estilização avançada com CSS.

 🚀 Tecnologias

* HTML
* CSS
* JavaScript

🎨 Foco do projeto

* ✔️ Construção de interface moderna
* ✔️ Organização de layout
* ✔️ Responsividade
* ✔️ Detalhamento visual


📌 Objetivo

Projeto voltado para prática de desenvolvimento frontend, com foco na criação de interfaces bem estruturadas e visualmente consistentes.

 📈 Aprendizados

* Estruturação de layouts complexos
* Uso avançado de CSS
* Organização visual de componentes
